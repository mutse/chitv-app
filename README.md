## Stream Videos, Anytime, Anywhere

ChiTV is a cross-platform video streaming app built with SwiftUI, supporting macOS, iOS, and tvOS for the ultimate viewing experience. Android is built with Flutter.

## Platforms

- macOS, iOS, and tvOS (native SwiftUI build)
- Android (Flutter build)

## Core Features

- **Cross-Platform** — Build once, run everywhere. Supports macOS, iOS, and tvOS for a consistent experience on any device.
- **Smart Search** — Powerful video search engine to quickly find what you want to watch, with search history support.
- **HD Streaming** — HLS streaming protocol support with adaptive bitrate switching for smooth HD video playback.
- **Bookmarks** — Bookmark your favorite videos with one tap. Local persistent storage ensures your data is never lost.
- **Watch History** — Automatically tracks your viewing progress and history for easy resume. Smart sorting shows recent watches first.
- **Dark Theme** — Carefully designed dark theme to protect your eyes and enhance immersion. Supports light/dark theme switching.

Local favorites and watch history work without an account. On Apple platforms, signing in to iCloud enables cloud sync across devices via CloudKit.

## Android

ChiTV is a video streaming app built with Flutter/Dart, supporting on-demand playback from VOD/CMS sources and live TV from live sources, for the ultimate viewing experience.

- **A binge-watcher's secret weapon** — Douban trending on the home screen, browsable by category; Continue Watching picks up right where you left off.
- **One search box settles tonight's pick** — Aggregated search · filter sources freely · one-tap resume for what you’ve watched
- **Douban trending: top-rated picks at a glance** — Douban scores upfront · movies and series trending together · tap to search
- **One-tap favorites, progress never lost** — Favorites, history and continue-watching in one · saved locally, resume anytime
- **Jump to any episode in a second, next episode in one tap** — Search by name · jump by episode number · progress at a glance
- **One-tap live switching, favorite any channel** — Search by channel, group or logo · zap up and down fast · program guide anytime

Tech highlights, tuned for Android: Flutter, Dart, HLS, Riverpod, Hive, Dio, Material 3.
